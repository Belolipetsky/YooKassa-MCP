# Чек-лист реализации

- API-клиент серверный, HTTPS, Basic Auth сформирован без логирования.
- Денежные значения не используют float.
- POST содержит сохраненный `Idempotence-Key` длиной не более 64 символов.
- Retry ограничен и повторяет тот же ключ.
- Внутренние записи хранят ID и статусы объектов ЮKassa.
- Проверяются сумма, валюта, принадлежность заказа и допустимый переход.
- Webhook допускает повторы и изменение порядка событий.
- До обработки webhook объект повторно запрашивается через API.
- В логах нет secret key, Authorization, email, телефона и полных карточных данных.
- Запросы с чеком проходят офлайн-валидацию.
- Unit, contract и test-store проверки проходят.
