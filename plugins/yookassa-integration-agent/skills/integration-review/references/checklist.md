# Чек-лист ревью

- Secret key отсутствует в клиентском коде, git, логах и сообщениях ошибок.
- Test и production конфигурации разделены.
- Все write-вызовы выполняются только доверенным сервером.
- POST использует сохраненный стабильный `Idempotence-Key`.
- Retry не меняет ключ и имеет предел/backoff/jitter.
- Деньги представлены точным типом.
- Redirect не подтверждает оплату.
- Webhook повторно проверяет объект через API и идемпотентен.
- Проверяются сумма, валюта, заказ и допустимые статусы.
- Частичные capture/refund корректно отражены в данных и чеках.
- Чеки покрывают customer/items/НДС/предмет/способ расчета/ФФД.
- PII минимизированы, логи редактируются.
- Есть позитивные, негативные, повторные и race-тесты.
- OpenAPI и changelog проверяются перед релизом.
