# Технический чек-лист чека

- Подтверждены схема фискализации, ФФД и система налогообложения.
- Для покупателя передан допустимый email или phone.
- У каждой позиции есть `description`, `quantity`, `amount`, `vat_code`, `payment_subject`, `payment_mode`.
- Сумма позиций равна сумме соответствующего расчета.
- Частичный capture содержит позиции и количества только подтверждаемой части.
- Частичный refund содержит позиции и количества возвращаемой части.
- Для маркированных товаров проверены `measure`, `mark_quantity` и отраслевые реквизиты.
- Тип чека согласован с событием payment/refund.
- Чек связан с корректным `payment_id` или `refund_id`.
- Статус чека проверяется в тестовом магазине.
- Налоговые значения подтверждены ответственным специалистом.
- Перед production проверены актуальные документы ЮKassa и ФНС.
