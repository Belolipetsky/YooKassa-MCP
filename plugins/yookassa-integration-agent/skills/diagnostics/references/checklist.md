# Чек-лист диагностики

- Пользователь подтвердил, что проверяется тестовый магазин.
- `yookassa_diagnose_connection` выполнен первым.
- Получено `testMode: confirmed`.
- Диапазон времени и ID сведены к минимально необходимым.
- Сравнены внутренний заказ, payment, refund и receipt.
- Проверены сумма, валюта, статус и cancellation details.
- Проверены повторы и порядок webhook.
- Проверен исходный `Idempotence-Key` без вывода его чувствительного контекста.
- Ошибка объяснена через HTTP status/code/parameter/description.
- В отчете нет секретов и PII.
- При production или неопределенной среде живые вызовы остановлены.
